## ملفات مهمة

- `رسائل_الواتساب.md` - رسائل إقناع جاهزة لكل محل + روابط wa.me برسالة جاهزة
- `index.html` - دليل كل المحلات

## تقنية

HTML + CSS فقط، بدون مكتبات خارجية. كل صفحة قائمة بذاتها (ما عدا CSS المشترك في `assets/style.css`).

## تخصيص صفحة لمحل

1. انسخ مجلد `stores/slug` وسمّه باسم المحل
2. عدّل الاسم والوصف والألوان (متغيرات CSS في أعلى الصفحة `--accent`)
3. عدّل أرقام الواتساب في أزرار الطلب
